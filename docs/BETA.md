# 公開 Beta 試用指南

[English](BETA.en.md) · 繁體中文

謝謝你願意試用 Leafpile！這一輪只想知道一件事：**「筆記 → 簡報 → 講後筆記」這一圈，第一次用的人走不走得完。**

大約 30 分鐘。不用安裝、不用註冊，你的檔案不會上傳到任何地方。

## 準備

- 電腦版 **Chrome 或 Edge**（其他瀏覽器可以閱讀與播放，但不能存檔，這一輪走不完）。
- 下載[範例書庫](https://github.com/ToruSmith/Leafpile/releases/latest)（`Leafpile-library-*.zip`），解壓到桌面。
- 打開 <https://torusmith.github.io/Leafpile/>，按「開啟本機資料夾」，選剛剛解壓的資料夾，瀏覽器問權限時選「允許」。

卡住超過 3 分鐘就跳到下一步，並記下卡在哪裡。**卡住本身就是最有用的回饋。**

## 七個步驟

1. **寫一篇筆記**：在「我的書庫」頁面，搜尋框旁邊按「+ 筆記」（沒看到這個按鈕、只看到「唯讀」，代表書庫沒有寫入權限，請回首頁重新按「開啟本機資料夾」並選「允許」）。主題選「讀書筆記」。寫一個標題、兩三個 `##` 小標，每個小標下寫幾行。在內文輸入 `[[`，連到書庫裡的「歡迎使用 Leafpile」。按 Ctrl+S 存檔。
2. **快閃播放**：在你的筆記右上按「▶ 快閃播放」（或按 P），用方向鍵看一遍，按 Esc 回來。這一步不會產生任何檔案。
3. **做成簡報**：筆記右上按「做成簡報」。它會在 `slides/` 建立一份新簡報並打開。按 E 改其中一張投影片的文字，存檔。
4. **上台演練**：在簡報裡按 S 打開講者視窗（瀏覽器擋彈出視窗時請允許）。在講者視窗按 **Q**，記下兩個「假裝觀眾問的問題」，其中一題寫上答案。
5. **講後筆記**：回到簡報畫面，按 Ctrl+K（Mac 是 ⌘K），選「把這份簡報存成講後筆記」。打開產生的筆記，確認剛剛的問答有在裡面。
6. **（選做）來源提醒**：回到第 1 步的筆記，加一句話存檔，再打開那份簡報。應該會看到「來源筆記改過了」的提醒；按 Ctrl+K →「標記簡報已跟上來源筆記」。
7. **回報**：填[試用回饋表](https://github.com/ToruSmith/Leafpile/issues/new?template=beta-feedback.yml)（需要 GitHub 帳號）。沒有帳號的話，把回饋表的問題回答在訊息裡傳給邀請你的人也可以。

## 回報時請不要貼

你自己的私人筆記內容、Email、電話。需要附畫面時，用範例書庫或隨手寫的內容重現就好。

## 這一輪不測的東西

畫布、手機上的編輯、多人協作。這些還沒做，不用回報「沒有」。
