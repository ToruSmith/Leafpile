# 筆記與簡報的互通（Leafpile 的特色）

## 一條原則

> **筆記是知識的唯一來源，簡報是一次演出。**

所以：內容可以跨渠道**引用**，也可以**複製一次**；但永遠不**自動雙向同步**。

為什麼不同步：簡報應該比筆記短、比筆記口語、常常重新排順序。雙向同步會讓兩邊互相覆蓋，最後誰都不敢改。

## 五種走法（加上畫布）

由上到下，對檔案的影響越來越大。

### 1. 連結

```markdown
相關：[[兩個渠道]]、[[兩個渠道#一句話]]、[[slides:2026-11-leafpile-tour]]
```

- 筆記與投影片都可以寫。
- 不改任何檔案。
- 筆記閱讀頁右側欄顯示**反向連結**：哪些筆記、哪些簡報連到這篇。簡報只算一個節點（不是每張投影片），避免圖譜被投影片淹沒。

### 2. 快閃播放

筆記右上角 ▶，把筆記暫時拆成投影片播放：

- 拆張規則：有單獨一行的 `---` 就依它拆；否則依 `##` 拆；第一個 `#` 當標題頁。筆記的 `##` 在投影片上顯示成標題。
- 版型全部用 `auto`；front matter 只讀 `title` 與 `date`。
- 不能在播放器裡編輯或檢查（那是暫時的投影片）；要改請回筆記。
- **不產生任何檔案**；可以用畫筆，但畫的內容不會存。
- 適合臨時在會議中分享筆記。要正式上台，請用「升級成簡報」。

### 3. 摘錄嵌入

投影片裡**單獨一行**寫：

```markdown
![[兩個渠道#一句話]]
```

- 播放時讀取那一段筆記（到下一個同級或更高級標題為止），放在投影片上。
- 唯讀：在投影片上不能改它，要改請回筆記。
- 檢查工具：摘錄超過 120 字提醒「簡報應該比筆記短」；找不到段落時報錯。
- 匯出單一 HTML 時，摘錄的內容會一起內嵌（匯出當下的版本）。
- 找不到來源時顯示原本的文字，播放器的提醒會列出來。
- Mdslide Pile 與匯出後離線開啟的舊檔不認得這個語法，會顯示成文字。

### 4. 升級成簡報

在筆記上按「做成簡報」（筆記本裡的筆記可以選擇整本一起升級），或執行 `node scripts/promote.mjs <書庫> <筆記或筆記本的路徑>`：

| 筆記裡 | 變成 |
|---|---|
| `title` 或第一個 `#` | `deck.yml` 的 `title` |
| 長筆記（有 `###`）：每個 `##` | 一個章節資料夾 `01-…/`，底下每個 `###` 一張投影片 |
| 短筆記（沒有 `###`）：每個 `##` | 一張投影片，全部放在同一章 |
| 標題 | 投影片標題（所以筆記的小標請寫結論） |
| 清單、表格、引言、程式碼、圖片 | 留在投影片上 |
| 其餘的說明文字 | 講者備註 `Note:` |

圖片不會自動複製：升級後請把需要的圖放進簡報的 `media/`，檢查工具會列出找不到的素材。

- 新簡報放在 `slides/<同名主題>/<今天日期>-<名稱>/`，`deck.yml` 記錄 `source:`。
- **升級是一次性的複製**，之後兩邊各自獨立。
- 筆記閱讀頁的右側欄會列出「被這些簡報引用」。（比對修改時間、提醒「來源筆記已更新」尚未實作。）
- 筆記本升級時，每篇筆記是一個章節，筆記裡的每個 `##` 是一張投影片。
- 目標資料夾已經存在時會停下來，絕不覆蓋。

### 5. 講後筆記

播放簡報時按 Ctrl+K →「把這份簡報存成講後筆記」，或執行 `node scripts/after-talk.mjs <書庫> <簡報的路徑>`：

- 新增 `notes/<同名主題>/<今天日期>-<簡報名稱>-講後.md`。
- 內容：簡報大綱（每章標題、每張標題）、所有講者備註，以及留白的「現場問答」與「下次要改」。（講者視窗的「問答」分頁尚未實作，問答請先手動補上。）
- front matter 寫 `from_deck:`，`public` 預設 `false`。
- 範例：`content/notes/00-examples/2026-11-leafpile-basics/03-after-the-talk.md`。

### 6. 畫布（第三階段，尚未實作）

`boards/*.canvas` 可以同時放筆記卡與簡報卡，用線表示「升級自」「講後」「相關」。畫布只存位置與連線，不複製內容。從讀書筆記 Vault 移植，並保留 `x-` 自訂欄位。

## 刻意不做的事

- **不做雙向同步**：沒有「筆記改了簡報自動改」，也沒有反過來。
- **筆記裡不寫版型**：`layout`、`size`、`background` 只屬於簡報；筆記保持任何 Markdown 軟體都能讀。
- **不把每張投影片放進知識圖譜**：一份簡報在圖譜裡是一個點。
- **不在快閃播放存任何東西**：要存就升級成簡報。
- **不跨渠道搬檔案**：筆記不會「變成」簡報，只會產生新的簡報。

## 檢查工具的互通規則

| 情況 | 等級 |
|---|---|
| `[[連結]]` 找不到目標 | 警告 |
| `[[連結]]` 符合多個目標 | 警告（請改寫成路徑） |
| 投影片裡的 `![[摘錄]]` 找不到筆記或段落 | 錯誤 |
| `![[摘錄]]` 超過 120 字 | 警告 |
| `deck.yml` 的 `source` 不存在 | 警告 |
| 筆記 front matter 出現版型設定 | 警告（請移到簡報） |
| 急件沒有到期日、或已經到期 | 警告 |

警告不會讓檢查失敗（結束碼仍是 0），錯誤才會。
