# 三行語法就能跨渠道

```markdown
[[兩個渠道]]                    連到筆記
[[slides:2026-11-leafpile-tour]]  連到簡報
![[兩個渠道#一句話]]             把筆記的一段放進投影片
```

完整規則：docs/INTEROP.md　·　實例：[[兩個渠道]]、[[連結與摘錄]]

Note:
Mdslide Pile 會把這些語法顯示成文字；在 Leafpile 裡才會解析。投影片上的連結不能點（觀眾手上沒有書庫），滑鼠移上去會說明連到哪一篇；匯出的單一 HTML 也保留這個說明。下一張就是摘錄的實例。
