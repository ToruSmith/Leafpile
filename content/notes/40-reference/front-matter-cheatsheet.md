# 筆記 front matter 速查

全部欄位都可以省略；Obsidian 等軟體看得懂，也不會被 Leafpile 洗掉。

| 欄位 | 範例 | 說明 |
|---|---|---|
| `title` | `第 1 章 先寫結論` | 顯示名稱；省略時取第一個標題，再省略取檔名 |
| `date` | `2026-11-09` | 排序與顯示用 |
| `tags` | `[讀書會, 習慣]` | 標籤 |
| `public` | `true` | 筆記 > 筆記本 > 主題預設 > 私人 |
| `lang` | `zh-Hant` | `zh-Hant` 或 `en` |
| `aliases` | `[兩渠道]` | `[[連結]]` 也可以用別名找到這篇 |
| `pinned` | `true` | 急件，置頂首頁 |
| `expires` | `2026-12-31` | 到期後提醒下架（`pinned` 時必填） |
| `source` | `https://…` | 原始出處 |
| `from_deck` | `slides/…/2026-11-x` | 講後筆記的來源簡報 |

這個主題預設公開，所以這篇沒寫 `public` 也會被當成公開內容。
